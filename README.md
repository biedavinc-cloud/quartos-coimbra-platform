# quartos-coimbra-platform

Marketplace de logement étudiant à Coimbra + super admin (blog, plans, PSP africains)

## Stack
- React + Vite (Base44)
- Base44 entities, backend functions and connectors
- Payment providers: PayUnit, Flutterwave, Paystack, MTN MoMo, Orange Money, Wave, CinetPay, M-Pesa

## Modules
- Marketplace d'annonces (recherche, favoris, réservations)
- Blog éditorial géré depuis le super admin
- Plans de publication (1 / 8 / 20 / illimité)
- Super admin : utilisateurs, annonces, pays, plans, paiements, GitHub
